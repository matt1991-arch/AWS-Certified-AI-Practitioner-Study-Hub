
Deep Learning es un subcampo de [[ML]] que usa redes neuronales por capas inspiradas en el cerebro para aprender de grandes volúmenes de datos.

---
## Definición para entrenar
**ES:** El Deep Learning usa redes neuronales con muchas capas para aprender patrones complejos de imágenes, voz y texto. Necesita muchos datos y GPUs. Ejemplo AWS: Rekognition para imágenes, Polly/Transcribe para voz.
**EN:** Deep Learning is a subset of [[ML]] that uses multi-layer neural networks inspired by the brain to learn from large data. It powers vision and speech. Example AWS: Rekognition, Transcribe.
